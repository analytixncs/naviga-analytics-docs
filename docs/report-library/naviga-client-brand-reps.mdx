# NAVIGA-Client Brand Reps

**Type:** Clients

Brand focused client report.

:::info NAVIGA-Client Brand Reps Bundle

Brand focused client report.

**<a target="_blank" href="/downloads/report-library/naviga-client-brand-reps.tgz">NAVIGA-Client Brand Reps</a>**

:::

## Summary

This is a useful dataset if you want to see a list of your Advertisers and their Brands. In addition to their brands, it will also show you the following Brand Rep and Rep overrides.
1. Default Brand Rep - There can be up to four, but this report only shows the first one.
2. Product Group Override Rep - Overrides by product group, again only the first of four is shown.
3. Product Override Rep - Overrides by product, again only the first of four is shown.

<img src={Pasted_image_20260812151759} alt="Pasted image 20260812151759.png" />

## Description
Pulls in the Advertiser Brands and the associated Brand Reps -> Default, Product and Product Group based reps.  It defaults to only bringing in the first rep of each, however, you can easily update the Brand Rep dataset joins to bring in the other 3 reps for each group.  NOTE: Each set of Brand Reps (Default, Product, Product Group) can have up to 4 reps defined.
